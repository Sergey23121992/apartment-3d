# Интерактивный макет квартиры

Статический сайт для GitHub Pages. Вращение и масштабирование модели на компьютере и телефоне, полный и разрезанный 3D-макет, размерный план с масштабированием и перемещением, переход к комнатам, полноэкранный режим и копирование ссылки.

Сайт находится в `docs/`. В GitHub Pages выбран источник `main /docs`. Сборка и сервер не требуются.

Локальный запуск: `python3 -m http.server 8765 --directory docs`.

3D: `@google/model-viewer` 4.4.0, Apache-2.0, локальная копия в `docs/vendor/`. Модель и изображения находятся в `docs/assets/`.

## Статус геометрии

Черновой макет по эскизу. Чистые размеры рассчитаны по модели и отличаются от части исходных надписей, поскольку размерные цепочки эскиза расходятся. На размерном плане приведены обе группы значений. Высоты помещений и окон, толщина стен, положение и размеры дверей приняты для макета.

Ширины оконных проёмов: спальня 1340 мм, зал 2160 мм, кухня 1370 мм. Высота окон принята 1400 мм, подоконник +900 мм. Высота 1400 мм выбрана по типовому примеру производителя MELKE, а не как универсальное требование ГОСТ.

Источники: https://base.garant.ru/408478705/ и https://www.melke.ru/okna/.
